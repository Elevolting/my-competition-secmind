# 全项目质量排查与修复记录

目标：排查并修复整个套件中的质量问题和未完成能力。测试通过只证明对应测试覆盖的行为，不作为全项目完成的依据。本记录持续更新；当前目标尚未完成。

## 本轮变更：通用黑板入口

原实现只在渗透任务上强制黑板，普通内置模块和 MCP 可以从统一编排器直接执行。现已加入 `blackboard_coordinator.py`：每个非渗透步骤在执行前创建或恢复任务项目和意图，绑定唯一 Worker，校验项目/意图租约，工具回执写成事实，任务报告再提交黑板终态；黑板服务不可用、租约失效或事实提交失败时任务不会伪装成成功。演示模式把同一图结构写入 Ledger 快照，重试会从上一个事实创建新意图。公开 RunSummary 继续保持 `external_execution` 的旧语义，黑板状态保留在内部任务快照和路由标记中。

这项变更已经接入统一编排器的所有工具步骤。渗透任务在分类后由 `BlackboardCoordinator` 创建停用 Dispatcher 的预备项目，审批通过后 `penetration_module` 激活同一项目，由 Security Runtime Dispatcher 接管；其他模块和 MCP 步骤也在分类后建立项目、选步时建立意图，执行前领取并校验租约。普通任务不能因为远程黑板不可用而退回直接工具调用。`MCPRuntime` 只保留显式传入的低层取消测试钩子作为内部兼容路径；HTTP/MCP 生产适配器没有该绕过参数。
