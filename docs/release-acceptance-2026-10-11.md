## 上线风险门槛

- 认证与授权：用户已明确仅本机单用户使用。四个入口均确认监听 `127.0.0.1`；三个 API 已加载可信 Host 和浏览器写入 Origin 校验，统一 API 与 SecMind 的 WebSocket 已验证外站拒绝、本机事件正常读取。
- 安全边界：上传、URL/目标范围、MCP 文件/网络访问和审批已有专项测试；SecMind、统一 API、Runtime 的 Python 环境及 Node 全依赖审计均为 0 已知漏洞。仅本机开发模式的固定分析工具已核对并修复 Python 子进程的工作区模块劫持。
- 并发与恢复：任务幂等、审批回执、预算/超时和 SQLite 恢复已有测试；真实合成任务完成 SecMind partial 报告流程，Dispatcher 外部终态联调仍待补。
- 外部服务：模型 Provider、Burp/TscanPlus/Reqable、Security Runtime 可用性会影响对应功能；只在本地或授权目标验证。
