# 执行画布

工作台的「探索路径」现在采用执行清单、来源画布和节点详情三栏展示。执行清单优先展示运行、审批等待、失败、超时和待执行想法，完成与取消记录进入可展开的历史。

## 数据约定

`blackboard-graph` 保留 `nodes/edges`，返回 `schema_version: "1.1"`，同时提供 `result_items` 和执行摘要。一次探索仍产出一个 Fact，新增可选 `title/items`；条目保存稳定 ID、类型、标题、摘要、证据引用和可选 `finding_id`。原始输出继续保存，读取画布不会重新生成结果。

执行状态与漏洞验证状态分开。工具调用成功只代表执行成功；漏洞「已确认」要求现有 Finding、有效证据和覆盖这些证据的验证通过记录。Worker 自报的确认或排除不会直接获得对应验证状态。无法解析的旧记录展示为「历史原文」，无有效证据的陈述标记为「Worker 报告」。

来源关系区分引用事实、流程衔接和来源不明。Worker 作为想法的执行信息展示，不再充当多个分支共享的图节点。工具名称来自当前 attempt 的真实调用开始和结束事件，不能从意图描述推测。

Runtime 为领取与重试生成 attempt ID，并持久化执行阶段、完成、释放、取消和超时事件。`GET /projects/{project_id}/events?after=<cursor>&limit=200` 用于增量同步；工作台按项目事件 ID 去重写入 ledger，再通过现有 WebSocket 通知页面。

## 交互与动画

画布保留 HTML 原型的点阵背景和分层卡片，配色沿用工作台：深色为炭黑面板与青色强调，浅色为白色面板与湖蓝强调，外层背景透明以融入现有页面。浅色读取工作台的共享颜色变量，连线与卡片读取同一画布配色。顶部统计来自项目数据。左侧按执行、等待处理和完成历史分组，右侧用来源卡片、执行元数据、时间线和证据卡片展示详情。Cytoscape 负责布局、连线和视角，HTML 卡片同步其渲染坐标；拖动卡片直接更新对应节点位置，滚轮经过卡片时仍可缩放。明暗主题均采用相同的信息层级。

- 选择清单或节点会高亮其上游路径，详情可跳转来源、展开结果条目并查看证据。
- 搜索覆盖折叠历史、结果条目和证据引用，保留搜索结果的完整来源路径。
- 初始图用 Dagre 布局；增量更新保留已有节点位置。拖动、缩放或选择后暂停自动跟随，可通过工具栏重新跟随、查看全图或重新整理。
- 执行节点呼吸周期为 900ms，活动边流动周期约 700ms，新结果淡入 500ms，位置调整 380ms。
- 页面隐藏、同步异常、任务结束或减少动态效果模式下停止活动动画；接口错误保留最后一次成功数据。
- WebSocket 通知合并刷新，3 秒轮询负责恢复；同一任务至多一个图请求，切换任务会取消旧请求。
- 手机端默认执行清单，通过标签切换画布和详情，进入画布时使当前选择完整可见。

## 运行与验证

本次变更涉及工作台后端、Runtime 服务及 Dispatcher；使用新代码时需同时重启这些进程。Runtime 在打开数据库时执行增量表结构迁移，旧 Fact 与旧输出协议继续兼容。历史任务不会补造缺失的证据、工具事件和来源关系。本版提供实时查看与追溯，不包含动画回放。

前端验证使用 `npm test` 和 `npm run build`。浏览器回归使用 `python tests/blackboard-browser.py`，需本机 Chrome、Python 的 `websocket-client` 和运行于 `127.0.0.1:5173` 的 Vite；API 使用独立模拟数据，不会创建真实安全任务。

浏览器固定数据包含 30 个想法与 300 个结果条目，覆盖并发刷新、请求超时恢复、结果展开、证据搜索、来源高亮、刷新保留视角、任务切换、明暗主题、手机布局和减少动态效果模式，并检查 HTML 卡片与连线对齐、卡片拖动及滚轮缩放。另用简化分支数据生成视觉检查截图。两套后端的 pytest 覆盖结构化协议、旧格式兼容、持久化、重试事件、游标去重、审批与调用关联、证据验证状态，以及现有业务回归。
