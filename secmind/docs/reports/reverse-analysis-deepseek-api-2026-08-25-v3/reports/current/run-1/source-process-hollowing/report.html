管理摘要

已识别完整进程镂空链（Process Hollowing, T1055.012）。恶意样本通过创建挂起进程、卸载原镜像、写入恶意代码并恢复线程，实现代码执行与隐蔽驻留。建议立即隔离主机并溯源入侵路径。

逆向分析

静态分析确认样本包含完整的进程镂空（Process Hollowing）实现链：1) 使用CreateProcessA创建挂起状态的合法进程；2) 通过NtUnmapViewOfSection卸载目标进程内存中的原始镜像；3) 分配新内存区域并写入恶意载荷；4) 修改线程上下文（如EAX寄存器）指向新入口点；5) 调用ResumeThread恢复执行。证据显示该技术符合MITRE ATT&CK T1055.012，属于进程注入的子技术，用于规避安全检测并隐蔽执行恶意代码。

证据边界

静态/模拟证据边界：除非封存证据明确标记 observed_runtime，本报告不得将事实视为宿主原生运行时观测。

发现与风险

进程镂空注入技术

critical置信度 high

业务影响 攻击者可在受感染主机上以合法进程身份执行任意代码，绕过基于进程白名单的防御，可能导致数据泄露、勒索软件部署或横向移动，对业务连续性和数据机密性构成严重威胁。

技术说明 样本通过Windows API组合实现进程镂空：CreateProcessA以CREATE_SUSPENDED标志创建合法进程；NtUnmapViewOfSection卸载原始可执行映像；VirtualAllocEx分配新内存并写入恶意代码；SetThreadContext修改入口点；ResumeThread启动恶意线程。该链完全匹配T1055.012，静态证据充分，无运行时观测。

给人类决策者的建议

P0

立即隔离受影响主机并终止可疑进程树

适用角色 security_operations

理由 进程镂空高度隐蔽且可执行任意载荷，可能已造成未授权代码执行。

预期结果 遏制恶意代码运行，防止进一步横向扩散和数据外泄。

P1

采集内存镜像与进程调用栈以确认载荷内容

适用角色 incident_response

理由 需确认写入的恶意载荷及其功能，评估影响范围。

预期结果 获取可操作的IOC和攻击者意图，支撑后续取证与清除。

P2

审查端点检测与响应规则以增强对进程镂空链的告警

适用角色 security_engineering

理由 现有防线被绕过，需要补齐针对挂起进程创建、内存写入、线程恢复的检测。

预期结果 提升对类似T1055.012手法的识别率，减少未来事件失察风险。

后续步骤

  • 分析内存转储以提取注入的恶意代码样本
  • 检查同一主机上其他进程的内存区域是否包含异常代码
  • 将样本哈希和IOC发布到威胁情报平台
  • 开展端点检测日志回溯以识别最早攻击时间点
  • 评估关联的网络流量以确认命令与控制通信
