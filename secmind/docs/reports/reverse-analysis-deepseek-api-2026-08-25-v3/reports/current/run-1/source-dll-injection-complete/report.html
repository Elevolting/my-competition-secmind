管理摘要

静态分析确认存在完整的 DLL 注入链，映射到 MITRE ATT&CK T1055.001。攻击者可通过注入恶意 DLL 在目标进程中执行任意代码，规避安全控制并窃取敏感数据。建议立即启用进程注入防护并实施 DLL 加载验证。

逆向分析

静态逆向分析发现样本包含完整的 DLL 注入链，涉及进程创建、内存分配、远程线程创建及 DLL 路径写入等关键步骤。注入技术符合 MITRE ATT&CK T1055.001（Process Injection: Dynamic-link Library Injection）模式。具体注入流程包括：1) 打开目标进程句柄；2) 在目标进程内分配内存并写入 DLL 路径；3) 创建远程线程指向 LoadLibrary 以加载恶意 DLL。由于缺乏运行时观测，未确认实际触发条件。

发现与风险

完整 DLL 注入链可执行任意代码

Critical置信度 High

业务影响 攻击者可在目标进程中以受害者权限执行任意代码，可能导致数据泄露、持久化驻留、横向移动及安全防御绕过，严重危害业务连续性和数据机密性。

技术说明 静态证据显示样本采用标准 DLL 注入技术（T1055.001）。通过远程线程调用 LoadLibrary 加载恶意 DLL，实现代码注入。该行为封装了完整的注入链，包括获取目标进程句柄、分配远程内存写入 DLL 路径以及创建远程线程触发加载。此类技术广泛用于恶意软件逃避检测和权限维持。
