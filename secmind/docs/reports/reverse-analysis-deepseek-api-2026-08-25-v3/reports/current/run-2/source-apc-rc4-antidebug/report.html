管理摘要

在封存证据中识别到四项高风险行为：APC 注入、RC4 加密负载解密（动态解析原生加密 API 实现）、原生 API 动态解析以及通过 NtQueryInformationProcess 进行反调试。这些行为共同表明样本具备隐蔽执行和规避检测的能力，对受保护环境构成重大威胁。

逆向分析

静态分析证据（observation_type: static；证据边界为静态或模拟）显示：样本通过异步过程调用（APC）实现进程注入（T1055.004），利用动态解析原生 API（T1106）获取 NtQueueApcThread 等关键函数地址；同时使用 RC4 算法对加密负载进行解密（T1027，行为 ID 为 encrypted_payload_decryption，具体 API 实现通过动态原生 API 解析获得）；对抗分析方面，样本调用 NtQueryInformationProcess 查询 ProcessDebugPort 等调试标志（T1622，行为 ID ntqueryinformationprocess_debug）。这些行为协同可支持无文件执行、内存载荷落地及反调试延迟分析。

证据边界

静态/模拟证据边界：除非封存证据明确标记 observed_runtime，本报告不得将事实视为宿主原生运行时观测。

APC 注入实现隐蔽代码执行

critical置信度 high

业务影响 攻击者可借助合法进程上下文执行恶意代码，规避基于进程创建或模块加载的检测，直接威胁终端与服务器安全。

技术说明 样本使用 APC 将恶意线程函数注入目标进程，结合动态解析 NtQueueApcThread 等原生 API 实现跨进程执行，属于 T1055.004 子技术，可提高隐蔽性并扩大攻击面。
